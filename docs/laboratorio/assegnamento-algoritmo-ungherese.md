# Assegnamento: l'algoritmo ungherese

Riduzione per righe e per colonne, copertura degli zeri con il minimo numero di linee, aggiustamento della matrice e assegnamento ottimo. ◀ ▶ un passo alla volta, «Esegui» per vederli tutti; il menu «Istanza», «Casuale» e «Modifica…» cambiano l'istanza.
